# Fitness App
 
Developed a user-friendly fitness tracking application using Java and XML for Android. The app allows users to log workouts, track their fitness progress, and stay motivated through a clean and intuitive interface.

🔑 Key Features:
Workout Logging: Users can input daily workout details including exercise type, duration, and calories burned.

Progress Monitoring: Visual summaries of progress using graphs and statistics to help users stay on track with their fitness goals.

Exercise Categories: Supports multiple workout types such as cardio, strength training, yoga, and custom routines.

Clean UI/UX: Designed with XML layouts to ensure a clean, minimal, and responsive user experience.

Data Persistence: Utilized SQLite for local storage of workout logs, ensuring data is retained between sessions.

Goal Setting: Users can set fitness goals and track their achievement over time.

Reminders & Notifications: Optional alerts to remind users to stay consistent with their workout routines.

🛠 Technologies Used:
Java for business logic and activity lifecycle handling

XML for building structured, responsive UI layouts

SQLite for local database management

Android Studio as the development environment
